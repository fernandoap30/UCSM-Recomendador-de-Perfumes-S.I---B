# UCSM-Recomendador-de-Perfumes-S.I---B
El presente repositorio muestra un sistema de recomendacion basado en prolog para ayudar a elegir un perfume a las personas

NOTA: PARA EJECUTAR CORRECTAMENTE EL ARCHIVO PROLOG REALIZAR LOS SIGUIENTES PASOS:
-consultar el archivo pl desde el programa de prolog
-el comando para iniciar el programa es: 

iniciar_recomendacion.

-Posteriormente, la lista usa el siguiente formato de ejemplo:  

[limon,naranja,bergamota].

-Finalmente, para indicar la duracion, se debe poner el punto final, por ejemplo:

media.
